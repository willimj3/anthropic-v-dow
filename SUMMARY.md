## What was built

A complete Next.js 15 + Tailwind 3 + MDX scaffold for the
*Anthropic v. Department of War* explainer and tracker site, populated end-to-end
from the seed materials in this folder.

**Routes (all rendering, all data-driven):**

- `/` — Overview: status snapshot + three docket cards + "What's next" + about-this-site
- `/case` — Long-form MDX explainer (~2,500 words) — Background, the three Challenged Actions, the complaint, the PI ruling, the D.C. Circuit case, the stayed 9th Circuit appeal, commentary landscape, what to watch
- `/timeline` — Vertical chronological timeline with sticky month headers and kind-color coding (24 events)
- `/dockets` — All three dockets at a glance, with entry counts
- `/dockets/ndcal` · `/dockets/dccir` · `/dockets/ca9` — Full docket sheets with high-importance section pinned to top (154 / 85 / 17 entries)
- `/parties` — Plaintiff, all 18 named defendants/officials, counsel, and ~25 amici
- `/claims` — The five counts with status-at-PI and current status
- `/issues` — Index of doctrinal issues
- `/issues/[slug]` — Per-issue pages: First Amendment retaliation, due process, APA-supply-chain, ultra vires, FASCSA jurisdiction, Webster v. Doe, Bill of Attainder, pretext doctrine
- `/holdings` — Court rulings to date, in reverse-chronological order with key-quote callouts
- `/commentary` — Curated annotated bibliography (analysis / news / brief)
- `/news` — Auto-aggregated news (currently three approved entries, more queued)
- `/study-guide` — All 54 Anki cards rendered as expandable Q/A, grouped into 13 thematic sections
- `/documents` — Index of high-importance filings across all three dockets + local source-doc mirrors
- `/updates` — Site changelog
- `/about` — Methodology, license, corrections

**Scripts (`/scripts/`):**

- `build_docket_yaml.py` — Re-generates the three docket YAMLs from the source TSVs, with regex-based importance classification. Idempotent but will clobber manual annotations — see the warning comment at the top of each generated YAML.
- `build_study_guide.py` — Re-generates `data/study-guide.mdx` from `02-anki-deck.csv`. Safe to re-run any time.
- `fetch_pdfs.py` — Downloads high-importance PDFs from CourtListener into `source-docs/`. **Requires a `COURTLISTENER_TOKEN`** — see "What still needs your decision" below.

**Monitoring layer (`app/api/cron/`):**

- `recap-poll/route.ts` — Daily RECAP poll; opens a GitHub issue per high-importance new filing; emails a plain-text digest. Requires `COURTLISTENER_TOKEN`, optionally `GITHUB_TOKEN`/`GITHUB_REPO`, optionally `RESEND_API_KEY` or `POSTMARK_TOKEN`, and `CRON_SECRET` (mandatory).
- `news-poll/route.ts` — Daily news RSS poll with weekly summary on Mondays; emails a plain-text digest. Requires `CRON_SECRET`, optionally email keys.
- Both handlers refuse to run without the required env vars. **Cron schedules are intentionally disabled** — see `vercel.json` (`_disabled_crons`).

## What was stubbed or skipped

1. **`source-docs/*.pdf`** — 93 PDFs (~68MB) downloaded via `scripts/fetch_pdfs.py`:
   - **14 ndcal** PDFs (entries 1, 6, 21, 34, 54, 73, 74, 77, 96, 113, 134, 135, 141, 145). Four "high" entries (5, 38, 136, 154) have not yet been ingested into RECAP — re-run the script later to pick them up.
   - **~71 dccir** PDFs covering every filing the D.C. Cir. has accepted: petition, emergency motion, opposition, reply, both parties' merits briefs, the petitioner reply, all 20+ amicus briefs, the per-curiam orders (including the supplemental-briefing order), and the oral-argument minute entry.
   - **8 ca9** PDFs (the schedule notice, mediation questionnaire/order, the stay motion and response, and the order staying proceedings).

   PDFs are `.gitignore`'d, so the download is local-only. The plain-text extracts (`source-docs/01-complaint.txt`, `source-docs/134-pi-opinion.txt`) remain in place. Re-running `python3 scripts/fetch_pdfs.py` is idempotent — it skips files already on disk.

2. **Importance heuristic noise.** A few entries are mis-flagged — for example, the Ninth Circuit's "PRELIMINARY INJUNCTION SCHEDULE NOTICE" (entry 2) is currently `low` because the description also mentions "mediation questionnaire" (an exclude). Review and promote/demote in `data/dockets/*-entries.yaml`.

3. **Auto-summarized commentary/news.** Deliberately not built — spec §11 keeps a human in the loop for every promoted entry.

4. **Vercel cron schedule.** Disabled in `vercel.json` as `_disabled_crons`. Uncomment to enable; see "Launch checklist" below.

5. **Lighthouse audit.** Not run in this environment — re-run via `npx unlighthouse --site http://localhost:3000` locally if you want a numeric score.

6. **GitHub repo creation / push.** Not done — repo isn't initialized.

## How to run it

```bash
# First time
npm install

# Local dev server
npm run dev               # http://localhost:3000

# Production build (verifies type-checking, linting, static generation)
npm run build
npm start                 # serve the production build locally

# Regenerate the docket YAMLs from the raw TSVs (after a TSV update)
python3 scripts/build_docket_yaml.py

# Regenerate the study guide from the Anki CSV
python3 scripts/build_study_guide.py

# Download high-importance PDFs (after exporting COURTLISTENER_TOKEN)
python3 scripts/fetch_pdfs.py
```

## Launch checklist (when you're ready)

1. **Create the GitHub repo** and push:
   ```bash
   git init
   git add .
   git commit -m "Initial scaffold"
   gh repo create <owner>/anthropic-v-dow --private --source=. --push
   ```
2. **Add Vercel env vars** in the project settings:
   - `CRON_SECRET` — random string; also paste into Vercel's cron config
   - `COURTLISTENER_TOKEN` — from courtlistener.com/profile/api/
   - `GITHUB_TOKEN` — fine-grained PAT scoped to this repo, `issues: write`
   - `GITHUB_REPO` — `owner/anthropic-v-dow`
   - `RESEND_API_KEY` *or* `POSTMARK_TOKEN`
3. **Connect repo to Vercel** and let it auto-deploy from `main`.
4. **Smoke-test the cron handlers manually** from Vercel's dashboard:
   `GET /api/cron/recap-poll` with header `Authorization: Bearer <CRON_SECRET>`
   should return `{ok: true, ...}` and (if anything is new) open a GitHub issue.
5. **Enable the cron schedule** by un-renaming `_disabled_crons` → `crons` in
   `vercel.json` and pushing.
6. **Run `python3 scripts/fetch_pdfs.py`** locally to mirror the high-importance
   PDFs into `source-docs/`.
